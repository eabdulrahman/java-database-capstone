## Admin User Stories
As an Admin, I want to:
- Log into the portal with my username and password to manage the platform securely, so that I can add doctors to the portal, delete doctor's profile from the portal, and run a stored procedure in MySQL CLI to get the number of appointments per month and track usage statistics.
- I also want to log out of the portal, so that I can protect system access.

## Patient User Stories
As a patient, I want to interact with the portal, so that I can view a list of doctors without logging in to explore options before registering, sign up using your email and password to book appointments, log into the portal to manage my bookings, log out of the portal to secure my account, log in and book an hour-long appointment to consult with a doctor, and view my upcoming appointments so that I can prepare accordingly.

## Doctor User Stories
As a doctor, I want to log into the portal to manage my appointments, so that I can view my appointment calendar to stay organized, mark my unavailability to inform patients only the available slots, update my profile with specialization and contact information so that patients have up-to-date information, and view the patient details for upcoming appointments so that I can be prepared.
I also need to log out of the portal, so that I can protect my data.
