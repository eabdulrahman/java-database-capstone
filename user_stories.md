## User Stories
### Admin User Stories
- As an Admin, I should be able to a dashboard or a page, so that I can manage User access and credentials.
### Patient User Stories
- As a Patient, I should be able to access a web page, so that I can schedule appointments with doctors and view prescriptions.
### Docker User Stories
- As a Doctor, I should be able to have access to a portal, so that I can view my scheduled appointments with patients, and prescripe medication for patients.
